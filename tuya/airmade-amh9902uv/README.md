# 에어메이드 AMH-9902UV 가습기를 Home Assistant에 로컬로 연결하기

에어메이드 AMH-9902UV(2026년형) 가습기를 Tuya 클라우드를 거치지 않고 집 안 네트워크에서 직접 제어하는 방법입니다. tuya-local 통합과 이 레포의 기기 설정 파일을 쓰면 전원, 목표 습도, 분무 세기, UV 살균, 수면, 터보, 가열, 꺼짐 예약을 HA에서 조작할 수 있습니다.

## 공식 Tuya 통합 대신 tuya-local을 쓰는 이유

HA 공식 Tuya 통합으로 이 가습기를 추가하면 기기는 보이지만 엔티티가 하나도 생기지 않습니다. Tuya 클라우드가 이 기종의 기능 목록을 비워서 보내기 때문입니다. tuya-local은 기기와 직접 통신하고, 기기 설정 파일에 적힌 대로 각 값(DP)을 엔티티로 만듭니다.

## 준비물

- HACS가 설치된 Home Assistant
- Tuya 앱(또는 Smart Life 앱)에 등록된 가습기
- 가습기의 IP 주소 (공유기 관리 화면에서 확인. 고정 IP로 잡아 두는 것을 권합니다)

## 1. tuya-local 설치

HACS 기본 목록에서 "tuya local"이 검색되지 않으면 사용자 저장소로 추가합니다.

1. HACS > 오른쪽 위 메뉴 > 사용자 저장소
2. 저장소 `https://github.com/make-all/tuya-local`, 유형 "Integration"으로 추가
3. Tuya Local을 내려받고 HA를 재시작합니다.

## 2. 기기 설정 파일 넣기

tuya-local에 이 가습기 설정이 포함되기 전까지는 파일을 직접 넣어야 합니다. ([업스트림 PR](PR_LINK) 진행 중)

[`airmade_amh9902uv_humidifier.yaml`](airmade_amh9902uv_humidifier.yaml)을 HA 설정 폴더의 다음 위치에 복사하고 HA를 재시작합니다.

```
/config/custom_components/tuya_local/devices/airmade_amh9902uv_humidifier.yaml
```

HACS로 tuya-local을 업데이트하면 이 폴더가 새로 덮어써지면서 파일이 지워집니다. 업데이트한 뒤에는 다시 복사하세요.

## 3. 기기 추가

1. 설정 > 기기 및 서비스 > 통합 추가 > Tuya Local
2. 클라우드 도움 설정을 고르고, Tuya 앱의 사용자 코드를 넣은 뒤 화면의 QR 코드를 앱으로 스캔합니다. 기기 ID와 로컬 키를 자동으로 가져옵니다.
3. 가습기를 고르고 IP 주소를 넣습니다. 프로토콜 버전은 3.5입니다.
4. 기기 종류 목록에서 Airmade AMH-9902UV 설정을 고릅니다.

tuya-local은 제품 ID(`utoa6fsvsavogcb8`)로 설정 파일을 찾습니다. 목록에 보이지 않으면 2단계 파일 위치와 HA 재시작 여부를 확인하세요.

## 생기는 엔티티

설정 파일은 다음 엔티티를 만듭니다. 엔티티 ID는 HA 언어 설정과 기기 이름에 따라 달라지므로 종류만 적었습니다.

| 종류 | DP | 내용 |
|---|---|---|
| humidifier | 1, 13, 14, 101 | 전원, 목표 습도(45~95%, 5% 단위), 현재 습도, 모드(`normal`, `auto`) |
| fan | 1, 23 | 분무 세기. 33% = 1단, 66% = 2단, 100% = 3단 |
| switch | 16 | UV 살균 |
| switch | 108 | 수면 |
| switch | 104 | 터보 |
| switch | 103 | 가열(Warm mist) |
| select | 19 | 꺼짐 예약(cancel, 1h~6h) |

모드 `auto`는 앱의 "AI 60%" 기능입니다. DP29와 DP102는 뜻을 확인하지 못해 엔티티로 만들지 않았습니다.

## DP 표

Tuya 앱에서 기능을 하나씩 누르면서 HA에 기록된 값 변화로 확인했습니다.

| DP | 기능 | 값 |
|---|---|---|
| 1 | 전원 | true/false. 켤 때 켜짐→꺼짐→켜짐으로 잠깐 튑니다 |
| 13 | 목표 습도 | 45~95, 5 단위 |
| 14 | 현재 습도 | % |
| 16 | UV 살균 | true/false |
| 19 | 꺼짐 예약 | `cancel`, `1h`~`6h` |
| 23 | 분무 세기 | `level_1`~`level_3` |
| 101 | AI 60% | true/false. 켜면 DP13이 95로 바뀝니다 |
| 103 | 가열 | true/false |
| 104 | 터보 | true/false |
| 108 | 수면 | 문자열 `on`/`off` |
| 29 | 확인 못 함 | true/false |
| 102 | 확인 못 함 | 버튼을 누를 때마다 1초쯤 true가 됐다가 돌아옵니다 |

AI 60% 모드가 켜져 있는 동안에는 앱에서 터보와 가열을 눌러도 값이 바뀌지 않았습니다.

## 문제 해결

### 오류 904 또는 914 ("Check device key or version")

로컬 키가 맞지 않을 때 납니다. 가습기를 Tuya 앱에서 지웠다가 다시 등록하거나 와이파이를 새로 잡으면 로컬 키가 바뀝니다. 기기를 다시 추가해서 새 키를 받으세요.

### 기기 종류를 잘못 골랐을 때

tuya-local의 옵션 화면에서는 기기 종류를 바꿀 수 없습니다. 통합 항목을 지우고 다시 추가하세요.
